# Skill: Palette Building

Use this procedure when the user wants to grow, refine, or find a theme for their word palette.

1. Ask what theme, feeling, or direction they want to capture.
2. Use `suggest_related_words` to generate candidates.
3. Present the suggestions and invite the user to choose.
4. Confirm which words should be added to the palette.
5. Ask whether they want to explore another theme.
