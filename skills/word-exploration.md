# Skill: Word Exploration

Use this procedure when the user wants to explore a word's meaning, origin, connotation, or poetic use.

1. Identify the word the user wants to explore.
2. Use `consult_word_specialist` with the appropriate aspect.
3. Explain the findings in plain language.
4. Relate the word to the existing palette when relevant.
5. Ask a gentle follow-up question to deepen the conversation.
