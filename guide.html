How this repository runs

The same browser workspace can use a local Node server or the deployed Cloudflare Worker. Lambda is not currently in this repository’s request path.

1 · Browserindex.html sends the user’s message to /api/ask.
→
2 · RuntimeLocal: server.mjs and the Strands Agent SDK.
Production: src/worker.js on Cloudflare.
→
3 · Amazon BedrockThe runtime calls the Bedrock Converse API using the configured model and AWS credentials kept server-side.

Deployment path: GitHub Actions uploads HTML assets to Cloudflare R2, then deploys the Worker. Lambda: not used here; adding it would be a separate AWS deployment path.

Safety hook: Strands’ RateLimiterHook counts each tool call per request and cancels the tool through event.cancel_tool after the configured cap, such as three calls. This prevents runaway tool loops.

Hook model: a hook is deterministic code that intercepts agent-loop lifecycle events without changing the agent’s reasoning. A HookProvider registers callbacks such as BeforeInvocationEvent and BeforeToolCallEvent.

Good Neighbor Agents

Useful intelligence for shared work.

A compact guide for building agents that serve groups and community organizations—not just individual productivity. Start small, earn trust, and expand with the people who use the system.

Why group-first?

Neighborhoods, nonprofits, food banks, schools, libraries, and small local organizations often have high demand, limited staff, and repetitive work. A good agent reduces that load while keeping decisions, context, and care with people.

Design principles

Collective benefit

Optimize for the people and organization together, not only the loudest individual request.

Low barrier

Prefer clear language, simple setup, and workflows volunteers can understand.

Trust & transparency

Identify the agent, show uncertainty, and make human handoff easy.

Privacy & access

Use only the information needed and make outputs readable and usable for varied abilities.

Good starting points

Neighborhoods

Draft newsletters, answer service FAQs, summarize meetings, and route concerns.

Nonprofits

Draft donor notes, match volunteers, track grants, and summarize impact.

Food banks

Coordinate pickup appointments, donations, partners, and distribution reports.

Schools & libraries

Answer recurring questions, promote programs, coordinate events, and guide resources.

Starter prompt

Adapt this small, human-centered brief to your organization:

You are a helpful assistant for [Organization]. Welcome people warmly, answer questions using verified local information, help with [one repetitive task], and direct urgent or uncertain matters to a staff member. Protect private information. Keep answers clear and accessible.
