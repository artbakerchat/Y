Option A — Test the existing server.mjs (quick, works now): uses the original Bedrock call with no tool loop, good for testing the UI and basic chat; run: cd project/Y, npm install, create .env with AWS_REGION=ca-central-1 / BEDROCK_MODEL_ID=ca.amazon.nova-micro-v1:0 / PORT=3000, then npm start and open http://localhost:3000 (requires AWS credentials via AWS_ACCESS_KEY_ID + AWS_SECRET_ACCESS_KEY or aws configure). Option B — Test the Worker locally with Wrangler (tests the new agent loop): runs src/worker.js with the full tool loop, hooks, skills, steering, and multi-agent; run: npm install -g wrangler, then wrangler secret put AWS_ACCESS_KEY_ID, wrangler secret put AWS_SECRET_ACCESS_KEY, optionally wrangler secret put AWS_SESSION_TOKEN, then npx wrangler dev --local and open http://localhost:8787 (still calls real Bedrock endpoints so credentials are required).
