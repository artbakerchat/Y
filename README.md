Forge is a Bedrock agent workspace: a full-stack starter for a Strands agent backed by Amazon Bedrock where the browser talks only to the local Node server and AWS credentials are never sent to the client. To run: (1) Install Node.js 22+. (2) Run npm install. (3) Set AWS credentials via the normal credential chain. (4) Optionally copy .env.example to .env and set AWS_REGION and BEDROCK_MODEL_ID. (5) Run npm start then open http://localhost:3000. The server prefers Strands when available and falls back to the Bedrock Converse API. In production the Cloudflare Worker can use Amazon Bedrock AgentCore as the managed runtime via AGENTCORE_RUNTIME_ARN; the browser's word palette is passed with each request as: {prompt: '...', palette: ['anchor','summit','echo']}. AgentCore CLI: install with npm install -g @aws/agentcore, validate with agentcore validate, set account/region in agentcore/aws-targets.json, then use agentcore dev / deploy / status / invoke. AgentCore storage: palettes in S3 (FORGE_PALETTE_BUCKET), conversation messages in DynamoDB (FORGE_SESSION_TABLE, partition key session_id), 48h TTL enforced at read time; enable S3 lifecycle with aws s3api put-bucket-lifecycle-configuration and DynamoDB TTL with aws dynamodb update-time-to-live.
